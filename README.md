# Yami

A warm, non-judgmental AI nutrition companion — mobile-first prototype.

Single self-contained file, no build step and no dependencies. Open `index.html`
directly in a browser to run it.

## Flow
Greeting (Yami, arms open) → spiral transition → onboarding survey (name,
language, birthday, height/weight, gender, goal, diet, grocery habits) →
home → snap a meal → mock nutrition score + feedback → grocery list
(brand recommendations, Instacart connect mock, order now).
